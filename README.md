# Bima Studio Theme

WordPress portfolio theme for creative agencies and freelancers. Custom post types for portfolio, services, and testimonials.

PHP 8 + vanilla CSS + vanilla JS, no frameworks.

## Installation

1. Upload `bima-studio` to `/wp-content/themes/`
2. Activate in WP Admin → Appearance → Themes
3. Create pages: Home, About, Services, Portfolio, Contact
4. Configure social links and colors via Customize

## Custom Post Types

- **Portfolio** — client, category, URL, tech stack
- **Services** — title, description, icon
- **Testimonials** — client name, position, company
